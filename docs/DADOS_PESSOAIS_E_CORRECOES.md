# Dados pessoais e correções

O Monitor organiza documentos e registros publicados por órgãos públicos.
É um projeto independente; não substitui o portal oficial e não controla o
conteúdo publicado pelo órgão de origem.

A extração de PDF, o OCR, os vínculos entre registros e os resumos podem
errar. Uma fonte pública também pode conter identificadores pessoais que
não precisam ser repetidos na apresentação do projeto. Por isso existe um
canal para avisar sobre associação à pessoa errada, dado incorreto,
exposição desnecessária ou outro problema de apresentação.

Entre em contato com [henriqueogs@gmail.com](mailto:henriqueogs@gmail.com).
Informe o endereço da página, o problema e, se houver, a fonte que permite
conferir a correção. Não envie senha, CPF completo, documento de identidade
ou outros dados sensíveis para se identificar no primeiro contato.

O mantenedor analisa o registro e distingue uma correção do Monitor de uma
divergência que precisa ser tratada com o órgão que publicou a informação.
O contato não garante remoção automática nem altera a publicação oficial.
Relatos sensíveis devem ser enviados por e-mail; uma issue pública é
adequada apenas quando não expõe dados pessoais desnecessários.

Para falhas de segurança, use o relato privado descrito em
[`../SECURITY.md`](../SECURITY.md). Para conduta, consulte o
[`../CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md).

Este documento descreve o canal de correção. A revisão técnica de logs,
cookies, retenção e serviços de infraestrutura continua sendo um aceite
separado do inventário operacional; esta página não declara conformidade
jurídica nem anonimização completa da base.
